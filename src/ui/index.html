1. Coordinate Projection (WGS84 Spherical to Local Metric Cartesian)

Raw GPS tracks contain angular coordinates ($^\circ\text{Lon}, ^\circ\text{Lat}$). Because 1 degree of latitude $\approx 111.32\text{ km}$ while 1 degree of longitude at latitude $49.8^\circ$ is only $\approx 71.85\text{ km}$, raw Euclidean distance in degrees introduces massive distortion. We use conformal local equirectangular projection centered at origin $(lon_0, lat_0)$:

$$x = (lon - lon_0) \cdot \frac{\pi}{180} \cdot R \cdot \cos\left(lat_0 \cdot \frac{\pi}{180}\right)$$ $$y = (lat - lat_0) \cdot \frac{\pi}{180} \cdot R$$
where $R = 6,378,137\text{ m}$ (WGS84 Earth semi-major axis). Scale distortion is <0.05% over city scale.

2. Candidate Generation & Feature Formulation

For each GPS observation $P = (x_P, y_P)$ and directed candidate road segment from node $A = (x_A, y_A)$ to $B = (x_B, y_B)$:

Projection Parameter $t \in [0, 1]$:
$$t = \operatorname{clip}\left(\frac{(P - A) \cdot (B - A)}{\|B - A\|^2},\, 0.0,\, 1.0\right), \qquad Q = A + t(B - A)$$
Perpendicular Distance ($d_\perp$):
$$d_\perp = \|P - Q\|_2 = \sqrt{(x_P - x_Q)^2 + (y_P - y_Q)^2}$$
Heading Alignment Cosine:
$$\cos(\Delta\theta) = \cos(\theta_{\text{veh}} - \theta_{\text{arc}}) = \frac{\vec{v}_{\text{veh}} \cdot (B - A)}{\|\vec{v}_{\text{veh}}\| \, \|B - A\|}$$
Theoretical Gaussian Spatial Emission Likelihood:
$$P(z_t \mid c_j) = \frac{1}{\sqrt{2\pi\sigma_z^2}} \exp\left(-\frac{d_\perp^2}{2\sigma_z^2}\right), \qquad \sigma_z = 10\text{ m}$$

3. All 5 Model Formulations & Loss Functions

A. Logistic Regression (Linear & Probabilistic):
$$P(y=1 \mid \mathbf{x}) = \frac{1}{1 + \exp(-\mathbf{w}^T \mathbf{x})}$$ $$\mathcal{L}(\mathbf{w}) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right] + \frac{1}{2C} \|\mathbf{w}\|_2^2$$
B. K-Nearest Neighbors (Instance-Based):
$$\hat{p} = \frac{\sum_{i=1}^k w_i y_i}{\sum_{i=1}^k w_i}, \qquad w_i = \frac{1}{\|\mathbf{x} - \mathbf{x}_i\|_2 + \epsilon}, \quad k = 7$$
C. Random Forest (Ensemble Bagging):
$$P(y=1 \mid \mathbf{x}) = \frac{1}{B} \sum_{b=1}^B T_b(\mathbf{x}), \qquad I_{\text{Gini}}(p) = 1 - p_0^2 - p_1^2$$
D. XGBoost Classifier (Gradient Boosting — Selected Winner):
$$\mathcal{L}^{(m)} \approx \sum_{i=1}^N \left[ g_i f_m(\mathbf{x}_i) + \frac{1}{2} h_i f_m^2(\mathbf{x}_i) \right] + \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$$ $$g_i = \hat{p}_i - y_i \quad\text{(Gradient)}, \qquad h_i = \hat{p}_i(1 - \hat{p}_i) \quad\text{(Hessian)}$$
E. Multi-Layer Perceptron (Neural Network):
$$\mathbf{h}_1 = \operatorname{ReLU}(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1), \quad \mathbf{h}_2 = \operatorname{ReLU}(\mathbf{W}_2 \mathbf{h}_1 + \mathbf{b}_2), \quad \hat{y} = \sigma(\mathbf{w}_3^T \mathbf{h}_2 + b_3)$$ $$\mathcal{L}_{\text{BCE}} = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

4. Hidden Markov Model (HMM) & Viterbi Dynamic Programming

Classifiers evaluate each GPS observation in isolation, causing disconnected jumps when GPS signals drift. The HMM models sequential road graph topology:

Emission Likelihood:
$$\ln P(z_t \mid c_j) = \ln\left(P_{\text{XGBoost}}(c_j) + \epsilon\right)$$
Road Network Topological Transition Matrix:
$$P(c_j \mid c_i) = \begin{cases} 0.60 & \text{if } c_j = c_i \quad\text{(vehicle continues along same segment)} \\ 0.35 & \text{if } \operatorname{to\_node}(c_i) = \operatorname{from\_node}(c_j) \quad\text{(connected intersection turn)} \\ 0.05 & \text{if 1-hop reachable in road graph} \\ 10^{-6} & \text{otherwise (severe penalty for physically impossible street hopping)} \end{cases}$$
Viterbi Dynamic Programming Recurrence:
$$V_t(j) = \max_i \left[ V_{t-1}(i) + \ln P(c_j \mid c_i) \right] + \ln P(z_t \mid c_j)$$ $$\text{Backpointer: } B_t(j) = \arg\max_i \left[ V_{t-1}(i) + \ln P(c_j \mid c_i) \right]$$

5. Bayesian Hyperparameter Optimization (Optuna TPE)

Optuna builds a probabilistic surrogate model $P(x \mid y)$ where $x$ represents the hyperparameter vector and $y$ is the validation Macro F1 score:

$$P(x \mid y) = \begin{cases} l(x) & \text{if } y > y^* \quad\text{(top 15% configurations)} \\ g(x) & \text{if } y \le y^* \quad\text{(remaining trials)} \end{cases}$$ $$\text{Expected Improvement (EI): } \operatorname{EI}(x) \propto \frac{l(x)}{g(x)}$$
Hyperparameter regions with high $l(x)$ and low $g(x)$ maximize the probability of outperforming the current best cross-validation score.
